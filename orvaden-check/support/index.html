Support.

Start with the guidance below. If the issue continues, send us the app version, device model, and a clear description of what happened.

Email support

Contact Orvaden, LLC for help with Orvaden Check: support@orvaden.com.

Privacy

Learn what the current Orvaden Check build stores and how local files are handled. Read the Orvaden Check privacy notice.

Before contacting support

  1. Open More → Help & Readiness in Orvaden Check.
  2. Review Getting Started for an in-app walkthrough.
  3. Open Backup Health to verify your current backup status.
  4. Check device settings if camera, photos, files, or notifications are not working.

Protect your inspection data

Orvaden Check stores its working data locally. Create a current backup before uninstalling the app, resetting the device, or installing a test build that may replace your existing installation.

Verify the backup before relying on it. Use the backup preview to confirm the inspection, checklist, schedule, and managed-file counts. Keep the file in a location you can access later.

Notifications and reminders

  • Confirm notifications are allowed for Orvaden Check in device settings.
  • Use the in-app notification test under Help & Readiness.
  • Confirm the scheduled date and time are still in the future.
  • Review battery or notification restrictions if reminders are delayed on Android.

Reports, photos, and signatures

If a report is missing a photo or drawn signature, confirm the attachment is visible in the completed inspection, then regenerate the PDF. If the issue follows a restore, verify the backup preview includes the expected managed files.

What to include in a support request

  • Your iPhone or Android phone model and operating system version.
  • The Orvaden Check version and build shown under About Orvaden Check.
  • The steps you followed before the problem appeared.
  • The exact error message, plus a screenshot if one is available.

Do not email confidential reports, inspection photos, signatures, or backup files unless they are necessary for troubleshooting and you are authorized to share them.
